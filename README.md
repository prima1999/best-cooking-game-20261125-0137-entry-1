Kuali Rush — a fast, original cooking game: run a 3-minute shift, pick ingredients, chop, wok and grill them, assemble dishes on the plate and serve each order before its patience runs out. Four recipes, a combo system, and a rush hour in the last minute. Keyboard + mouse, desktop Chrome, no network requests, all art and sound drawn and synthesized in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. To build the hand-in output instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
